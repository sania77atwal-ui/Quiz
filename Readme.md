# Java Console Quiz

A beginner-friendly **Java console-based quiz project** created using VS Code.

## About

This project contains three different quizzes:

* Maths Quiz
* Java Quiz
* General Knowledge Quiz

The user answers multiple-choice questions through the console. The program checks each answer, gives feedback, and keeps track of the score.

## Features

* Multiple-choice questions
* User input using `Scanner`
* Case-insensitive answers
* Score tracking
* Final score out of 10
* Different responses for correct and incorrect answers
* Fun dare/challenge messages for some wrong answers

## Concepts Used

This project helped me practice:

* Java methods
* `Scanner`
* `String`
* `if-else`
* `equalsIgnoreCase()`
* Variables
* Score calculation
* Console input/output

## How to Run

Open the project in **VS Code** and run the Java `main()` method.

The quiz will start in the terminal/console.
